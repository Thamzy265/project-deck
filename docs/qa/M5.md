## PM check

Before you start: Claude Code CLI installed, this branch checked out in a folder you can use, about 5 minutes.

1. Optional: remove the old plugin. Skip this step if you never installed flutterdeck.

```bash
claude plugin uninstall flutterdeck@flutterdeck-dev
```

Expected: the old plugin is removed. If it says "not found", it was already gone: continue.

2. In the Pitdeck checkout folder, remember its path, add the marketplace from it and install the new plugin. Use the same terminal window for the next steps, so `PITDECK_DIR` stays set.

```bash
PITDECK_DIR="$(pwd)"
claude plugin marketplace add "$PITDECK_DIR"
claude plugin install pitdeck@pitdeck-dev
```

Expected: both commands succeed and say `pitdeck` was installed. If you see an unknown-plugin error, tell the lead.

3. Go to a Flutter project with Drift (`cd <your Flutter project>`), with the app running from your IDE, start the dashboard and a new Claude session there.

```bash
node "$PITDECK_DIR/packages/cli/dist/main.js" start
```

Expected: "Pitdeck started." and an address.

4. In the new Claude session type:

```text
/db how many orders are pending?
```

Expected: Claude uses the `pitdeck` MCP tools (`db_list`, `db_query`) and answers with a number. If the tools are listed as `flutterdeck`, redo step 1.

5. Clean up.

```bash
node "$PITDECK_DIR/packages/cli/dist/main.js" stop
```

Expected: "Pitdeck stopped."

PM check steps: not run by QA from a clean Claude profile (needs the PM's profile). Steps 3 and 5 use commands QA ran in criterion 1 and 2.
