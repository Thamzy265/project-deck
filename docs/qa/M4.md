- **N1 (minor, `/db` wording).** The skill says "show the SQL it ran". In A1 Claude ran `… WHERE status = ?` with `params: ["pending"]`, but showed `… WHERE status = 'pending'`. The two are equivalent, but the SQL shown is not the exact SQL that ran. A2 does the same.
- **N2 (minor, `/check` wording).** In A5 the reload had worked (the screen showed v2), but the Next line still guessed: "If the marker text still shows the old value on screen, it is likely a `const` widget …". It is not wrong, but it is noise in an "all clear" report.

- **N4 (information).** With two DTDs running (the QA app's and Android Studio's), `/check` connected to the right one each time.
