## PM check

Before you start: open a Flutter app in Android Studio, and have Node.js 22.12 or later and pnpm 10.

1. In Android Studio, start the app on the emulator. Wait until the app shows on the screen.
2. Build and test:
   ```bash
   cd ~/Developer/Personal/project-deck && git switch main && git pull && pnpm install && pnpm build && pnpm check
   ```
   Expected: the output ends with "Tests … passed" and shows no errors.
3. Find the app:
   ```bash
   node scripts/dtd-apps.mjs
   ```
   Expected: `1 app(s)` on the Android Studio line.
4. Start the daemon. Keep this window open.
   ```bash
   node packages/daemon/dist/main.js
   ```
   Expected: `project-deck daemon listening on http://127.0.0.1:<port>`.
5. In a second window, load the token and the port:
   ```bash
   cd ~/Developer/Personal/project-deck && TOKEN=$(node -p "require('./.flutterdeck/runtime.json').token") && PORT=$(node -p "require('./.flutterdeck/runtime.json').port")
   ```
   Expected: no output.
6. Get the status:
   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/api/status
   ```
   Expected: the app shows under `"attached"`, with an id that starts with `dart-`.
7. Change visible text in the app code and save. Then send a hot reload:
   ```bash
   curl -s -X POST -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/api/reload
   ```
   Expected: `"ok":true,"kind":"hot-reload"`, and the text changes on the emulator.
8. Read the logs:
   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:$PORT/api/logs?limit=10"
   ```
   Expected: lines that the app printed.
9. Stop the app in Android Studio. Run the command from step 7 again.
   Expected: `"reason":"not-attached"`.
10. Clean up: press Ctrl+C in the first window. Expected: the daemon stops in 1–2 seconds, and Android Studio continues to operate.

### Observations (not failures)

- **README step 5 and Android Studio's reload on save.** The README says "Edit `reloadMarker` … save, then reload through the daemon". Android Studio hot reloads on save by default, so the new text can come from the IDE, not from the daemon's reload. The PM check below edits the file from the terminal so the daemon's reload is what changes the screen. Whether an external edit also triggers the IDE reload was not observed (no IDE here).
- **README step 6 can miss the tap lines.** `limit=10` returns the newest 10 entries from all sources. On this fresh emulator, 7 of 10 were Android system lines (`ActivityThread`, GC). After a busy minute the `Tap N` lines can drop out. `&text=Tap` returns only the tap lines. Suggest the README use it.
- `startedBy` is `"unknown"` and `device.id` is `"unknown"` for an app started by `flutter run`. Not in the criteria.

### Not observed

- The real IDE breakpoint and the Android Studio reload-on-save behaviour: needs the PM's Android Studio (PM check below).
- `git switch main && git pull` in PM step 1: the branch is not merged yet. QA ran `pnpm install && pnpm build` on the branch.

   Expected: the emulator shows "FlutterDeck sample", "Edit me, then hot reload: v1", "Taps: 0" and a **Hit breakpoint** button.
3. Open `lib/main.dart`. Click in the gutter next to line 15 (it ends with `// FLUTTERDECK: put the breakpoint on this line`). A red dot shows.
4. Tap **Hit breakpoint** on the emulator.
   Expected: Android Studio stops on line 15 and highlights it. The screen still shows "Taps: 0". Press **Resume** (F9). The screen shows "Taps: 1". If it does not stop, check that you pressed Debug, not Run.
5. In a terminal, start the daemon. Keep this window open.
   ```bash
   cd ~/Developer/Personal/project-deck && node packages/daemon/dist/main.js
   ```
   Expected: `project-deck daemon listening on http://127.0.0.1:<port>`.
6. In a second terminal, load the token and the port:
   ```bash
   cd ~/Developer/Personal/project-deck && TOKEN=$(node -p "require('./.flutterdeck/runtime.json').token") && PORT=$(node -p "require('./.flutterdeck/runtime.json').port")
   ```
   Expected: no output.
7. List the apps:
   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:$PORT/api/apps" | node -e "for (const a of JSON.parse(require('fs').readFileSync(0, 'utf8'))) console.log(a.id, a.name)"
   ```

   Expected: a line with `Package: flutterdeck_sample`. Other apps you run can show too. If you see `Unauthorized`, redo step 6.

    Expected: no output. The screen still shows "v1".

    Expected: Android Studio stops on line 15 again, with the daemon attached. This is the main check. Press **Resume**. The screen shows "Taps: 2".
