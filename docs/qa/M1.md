## PM check

Before you start: open a Flutter app in Android Studio, and have Node.js 22.12 or later and pnpm 10.

Note: step 4 needs the daemon port fix (branch `fix/daemon-port`). Before that fix, use `--port 9147` in step 4, and use `9147` for `PORT` in step 5.

1. In Android Studio, start the app on the emulator. Wait until the app shows on the screen.
2. Build and test:
   ```bash
   cd ~/Developer/Personal/project-deck && git switch main && git pull && pnpm install && pnpm build && pnpm check
   ```
   Expected: the output ends with "Tests … passed" and shows no errors.
3. Find the app:
   ```bash
   node scripts/dtd-apps.mjs
   ```
   Expected: `1 app(s)` on the Android Studio line.
4. Start the daemon. Keep this window open.
   ```bash
   node packages/daemon/dist/main.js
   ```
   Expected: `project-deck daemon listening on http://127.0.0.1:<port>`.
5. In a second window, load the token and the port:
   ```bash
   cd ~/Developer/Personal/project-deck && TOKEN=$(node -p "require('./.flutterdeck/runtime.json').token") && PORT=$(node -p "require('./.flutterdeck/runtime.json').port")
   ```
   Expected: no output.
6. Get the status:
   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/api/status
   ```
   Expected: the app shows under `"attached"`, with an id that starts with `dart-`.
7. Change visible text in the app code and save. Then send a hot reload:
   ```bash
   curl -s -X POST -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/api/reload
   ```
   Expected: `"ok":true,"kind":"hot-reload"`, and the text changes on the emulator.
8. Read the logs:
   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:$PORT/api/logs?limit=10"
   ```
   Expected: lines that the app printed.
9. Stop the app in Android Studio. Run the command from step 7 again.
   Expected: `"reason":"not-attached"`.
10. Clean up: press Ctrl+C in the first window. Expected: the daemon stops in 1–2 seconds, and Android Studio continues to operate.
