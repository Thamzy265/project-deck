# Feedback

Feedback goes to a GitHub Discussions thread on the repo: <https://github.com/Thamzy265/project-deck/discussions/46>

- It is **public** and tied to your GitHub account. There is no email field and no other service.
- Answer the 12 numbered questions in the thread, for example `3: b`. Skip any you like.
- Do not paste app data, database rows, logs, tokens, VM service or web addresses (URLs) or personal data. If you got stuck, give the step number and the message you saw, with tokens and addresses removed. If you post something by mistake, edit or delete your reply (the … menu on your comment).
