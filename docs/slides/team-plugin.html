Options

Pin to v0.1.0, or follow the latest version?

Option A: pin to the v0.1.0 tag

  • project-deck changes only when you choose to upgrade
  • Each upgrade is a one-line PR
  • Not yet confirmed that project settings accept a pin; QA checks it

Option B: follow main

  • Fixes arrive without a PR
  • A skill change can change project-deck's process without you seeing it
  • Auto-update is off by default anyway, so each machine updates by hand

Recommendation

Option A, because a change to how the team works should go through you as a PR.

Security and privacy

Low risk: text and settings, no code

Trust boundary

A new outside source: the plugin is fetched from Thamzy265/my-tech-team on GitHub. It contains skills only, with no hooks, MCP servers or scripts.

Abuse case

A bad change to the skills repo changes how agents behave in project-deck.

Mitigation

Pin to a tag (Option A). Claude Code ignores repo settings until the folder is trusted. Upgrades go through a PR.

Privacy: no personal data is touched. Privacy regions stay UK + EU, because app logs and Drift databases may hold your app users' data.
